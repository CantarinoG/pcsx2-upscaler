# Material photos

The photos `material.py` takes fine detail from. They come from [Poly Haven](https://polyhaven.com/textures), published under [CC0](https://polyhaven.com/license), and were converted to 1024x1024 greyscale (only their luminance is used).

| File | Source | Used for |
|---|---|---|
| `concrete.jpg` | [Granular Concrete](https://polyhaven.com/a/granular_concrete) | grain, masonry |
| `rock.jpg` | [Rock Face 03](https://polyhaven.com/a/rock_face_03) | stone |
| `grass.jpg` | [Sparse Grass](https://polyhaven.com/a/sparse_grass) | grass |
| `wood.jpg` | [Weathered Planks](https://polyhaven.com/a/weathered_planks) | wood |
| `metal.jpg` | [Rusty Metal](https://polyhaven.com/a/rusty_metal) | metal |

To use another photo, replace the file with any seamlessly tiling square image.
